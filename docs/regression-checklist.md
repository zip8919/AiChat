# 回归清单

真机（Android 4.4.2 词典笔）手动回归用。按改动范围挑对应分组跑，不必每次全跑。

- 改**请求链路**：一、三、四组必跑。
- 改**输入与发送**：第二组。
- 改**附件、图片、多模态**：第四、五组。
- 改**模型 / 提供商 / 预设 / 占位符**：第六组。
- 改**主题与外观**：第六组第 50 条 + `docs/rendering-test-suite.md`。

## 一、请求链路与渲染

1. 普通对话：流式开 / 关各一次，中途长按打断。
2. 联网搜索：搜索 → 卡片 → 续写，卡片上的链接可点。
3. 工具轮次失败：错误卡片出现，「从出错处重试」能继续。
4. 首轮失败：用户消息上挂重试，点击后重发。
5. 排队：回复中发第二条，队列管理里上移 / 下移 / 插队。
6. 切会话 / 新建：进行中的请求被正确丢弃，不串消息。
7. 杀进程重进：历史消息、工具记录、来源都在。
8. 旧会话续聊：升级前的会话里带搜索卡片的回复，追问一句「刚才查到什么」，模型能说出当时的结论（验证 `ToolHistoryRecovery`）。
9. 排队 + 重试：回复中排队一条，再点「打断并重试」——重试要真的执行，排队那条在重试结束后发出（验证 `MessageQueue.pause/resume`）。
10. 多轮搜索（连续触发 5 次以上工具）：每轮卡片都应立刻出现，滑动不卡顿（验证增量渲染 + `TraceKit`）。
11. 生成中长按正在输出的气泡：弹出「复制已生成内容 / 选择文本 / 停止生成」。
12. 生成中含宽表格的回答：手指在表格上横向拖动，位置不能被重绘拉回（验证 `__holdRender`）。

## 二、输入与状态机

13. **发送键状态机**：输入框为空且生成中 → 显示方块（停止）；有文字 → 显示纸飞机（发送）；文字清空后立刻回到停止态，不能出现「既能发又能停」的中间态。
14. **全屏输入**：有文字时四角图标出现，点开编辑后「完成」回填、「取消」丢弃，返回键等同于取消且不改动原输入。

## 三、重试、元信息与首启

15. **429 重试**：断网 / 限流时自动重试，重试期间「停止」能立即打断等待；重试次数耗尽后错误卡片带「已自动重试 N 次仍失败」。
16. **Token 与时间**：每条消息底部显示时间；AI 消息带 token 与 tok/s；端点不支持 `stream_options` 时应自动降级且只降级一次，后续请求不再带该字段。
17. **首启引导**：清除数据后首启弹免责声明，确认前不会发出任何外部 Intent 带来的消息；「关于」页版本号与实际 APK 一致，「关于 → 使用说明」与首启弹窗文字完全相同。
18. **429 重试上限**：设置里能填到 20，填 21 会被夹回 20；填 0 会被夹回 1。
19. **429 退避按轮次独立**：基数设 1 s，用限流 Key 触发一次带工具的回复——第 1 轮连吃两次 429 后等 1 s、2 s；第 2 轮再遇到 429 必须重新等 1 s，不能变成 4 s。
20. **立即重试**：把重试次数设 3、间隔 10 s，用限流 Key 触发 429，卡片出现后点「立即重试」，应当立刻重发而不是等满 10 s；点「停止」仍然能中断。

## 四、附件与图片

21. **附件**：选一个 `.txt` → 输入框内容不变、上方出现文件标签；点标签可移除；发送后正文里不含任何附件元信息，气泡下方是独立的附件卡片；排队发送时附件不丢。
22. **思考块标题**：展开再收起后，括号里的 token 数不变（走 `data-tok`，不按可见文本重算）。
23. **附件真的被读到了**：附一个 `.txt` 只写「总结这个文件」，模型回答里必须出现文件内容的关键词；同一会话再追问细节，仍能答上来（说明历史回放也带了正文）。
24. **附件元信息**：标签第二行显示真实大小与 `~tokens`；10 MB 文件能附上，超 10 MB 报错。
25. **改消息不丢附件**：给一条带附件的老消息点「修改」，只改文字并确定——附件卡片必须还在原位，正文里不能冒出「[附件]」这一行。
26. **老会话迁移**：升级前带附件的会话打开后应显示为独立卡片，正文只剩用户原话；再追问一句文件里的细节，模型仍能答上。
27. **重试保留附件**：对带附件的用户消息点「重试」，重发的那条必须仍带附件卡片。
28. **token 估算**：纯中文 100 字左右应显示 `~60 tokens`，纯英文 400 字符左右应显示 `~120 tokens`；端点在流式里返回 `usage` 时应显示不带 `~` 的真实值。
29. **图片附件**：加号 → 添加图片 → 卡片上出现缩略图与「大小 · 尺寸 · 仅本机」；点卡片进图片查看器，可缩放 / 旋转；杀掉进程重进会话，缩略图与点开都还正常。
30. **图片不进请求体**：附图片后发一句问题，请求体里只有「[图片附件] x.jpg（…）」与「未包含图像内容」，不含 base64；模型不会声称看到了图。
31. **多模态输入**：DeepSeek Flash 系列默认已勾；附图发问——请求体是 `content` 数组（text + image_url data URI），模型能描述图片内容；取消勾选后回到纯文本路径（同第 30 条）。
32. **图片 token**：附一张 1024×1024 图，卡片显示 `~652 tokens`；卡片值应等于端点实际计费值；端点返回 `usage` 时以返回值为准、不带 `~`。
33. **图片 URL 导入**：加号 → 从链接添加图片 → 输入 https 图片地址，成功后进裁剪页；内网地址被拒。
34. **拍照 + 裁剪**：拍照 → 裁剪页框选 / 旋转 → 确认后卡片出现缩略图；选图文件同样先过裁剪页；取消裁剪不落任何附件。
35. **image_search**：问「搜几张橘猫的图」→ 出现图片网格卡片；点缩略图进图片查看器；视觉开启时追问「图里是什么」模型能答（只内嵌前 2 张）。

## 五、查看器与文档

36. **查看附件**：给消息附一个 `.java` → 点卡片，查看器顶部显示文件名、正文带颜色；Android 4.4 上横向滑动与缩放都跟手（源码不折行是刻意设计）。
37. **HTML/SVG 预览**：附一个 `.html`（含 `<style>` / `<script>`）→ 点卡片看到源码，右上角「预览」→ 变成渲染结果，按钮变「源码」可切回；`.svg` 同理，图形应居中且不被工具栏遮住。
38. **JS 运行**：附一个 `.js` → 右上角是「运行」而不是「预览」，点开进脚本运行器，控制台能打印 `console.log` 的输出。
39. **大文件**：附一个 2 MB 的日志 → 查看器只渲染前 40 万字符，顶部黄条说明已截断；滑动不能卡顿。
40. **md 预览**：附一个 `.md` → 右上角「预览」→ 渲染成排版文档，按钮变「源码」可切回；超 64K 的 md 只渲染前段。
41. **内网开关**：默认关闭时 `http://192.168.1.1` 被拒；开启（弹窗确认后）能连上；取消确认时开关自动拨回。
42. **证书开关**：关闭时访问自签证书站点失败并在错误详情里看到提示；开启后能连上。
43. **标题提示词占位符**：把标题提示词改成含 `{model}` 的文案，新会话生成标题后检查请求体里机器型号已被替换（日志里 `generate:` 一行可见）。

## 六、配置、预设与外观

44. **提示词预设**：设置页「保存为预设」→ 预设管理页出现新条目；单击预览 → 应用后主界面输入框被替换；重名保存自动编号，不会覆盖旧条目。
45. **提供商编辑**：改 Base URL / Chat Path，地址预览实时更新且不出现双斜杠；拉取远端模型后能勾选导入。
46. **模型编辑**：模型 ID 与显示名分开填；重名校验只在同一提供商下生效；显示名不影响请求体里的 `model` 字段。
47. **连通性测试**：正确 Key 显示耗时；错误 Key 显示归类后的原因（鉴权失败 / 网络不可达 / 证书错误）。
48. **默认模型与显示名**：给同一模型 ID 在两个提供商下各改一个显示名，主界面下拉能区分；重启后选中项不串到另一家。
49. **占位符胶囊条**：系统 / 标题 / 代码执行 / 主题模板四个输入框各显示对应集合；点一下插入到光标处，光标落在占位符末尾。
50. **主题动态着色**：新建一套带自定义色的主题后，列表行、对话框、Spinner 下拉项都跟着变色，而不是只有 ActionBar 变色；切回默认后界面与出厂一致，无残留色差。
