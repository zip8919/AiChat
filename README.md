# AiChat

> 跑在 Android 词典笔上的 AI 对话客户端。支持任意 OpenAI 兼容端点，消息用 WebView 渲染 Markdown 与 LaTeX。

AiChat 为词典笔这类屏幕小、配置低的老设备设计。模型可以是 DeepSeek、商汤日日新，也可以是你自己部署的任意 OpenAI 兼容服务。数据全部存在本机，不需要注册账号，也不上报任何统计。

## 核心功能

- **任意 OpenAI 兼容端点** —— 提供商与模型都能自己加，填 Base URL、Chat Path、API Key 即可；内置 DeepSeek 与商汤日日新配置，不含密钥
- **流式对话** —— 逐字输出，思考过程可折叠；回复中继续输入会自动排队，支持上移、下移、插队与打断
- **Markdown 与 LaTeX** —— 标题、列表、表格、引用、脚注、高亮、代码块与公式；代码块带语法高亮，可复制、可全屏、可导出
- **附件问答** —— 文本文件、图片、拍照、链接图片；单文件 10 MB，默认最多 5 个，正文随请求发给模型
- **看图** —— 支持多模态的模型可以直接读图；也能用图片搜索找到图后让模型看
- **联网搜索** —— Tavily（默认）或 DeepSeek 后端，可搜网页、搜图、抓正文；来源独立成折叠区，不混进正文
- **外观与主题** —— 显示大小、字号、字体、明暗；4 套内置主题（默认 / 纸墨 / 深夜 / 高对比），可导入 `.actheme`，也能让 AI 生成
- **429 自动重试** —— 指数退避并遵循服务端 `Retry-After`，等待中可一键立即重试
- **存储与用量** —— 五类占用一眼看清，无引用图片与残留临时文件可一键清理；按模型、服务商、工具统计 token
- **版本更新** —— 应用内检查 GitHub Release，按 ABI 选包，多镜像测速后下载安装

## 快速开始

**设备要求**：Android 4.4 及以上（minSdk 18）。ARM 设备选 `arm64-v8a` 或 `armeabi-v7a`，不确定就下 `universal`。

1. 到 [Releases](https://github.com/zip8919/AiChat/releases) 下载与设备 ABI 匹配的 APK。
2. 首次启动会显示使用说明与免责声明，点「同意并继续」。
3. 进入「设置 → 模型配置」，选一个提供商并填入 API Key；也可以新增自己的 OpenAI 兼容端点。
4. 返回主界面开始对话。

> 覆盖安装不会丢数据，升级包与原包签名一致。

## 使用

| 想做的事 | 怎么做 |
|---|---|
| 发附件 | 输入框左侧「+」：文本文件、图片、链接图片、拍照 |
| 联网搜索 | 设置里打开「联网搜索」，直接提问，模型会自己调用 |
| 换主题 | 设置 → 外观；可导入 `.actheme`，或让 AI 生成 |
| 找历史 | 长按底部「历史」进入会话管理，可重命名、批量删除 |
| 少占资源 | 关掉「流式输出」与「实时渲染」 |
| 升级 | 关于 → 检查更新 |

## 常见问题

**装不上，提示「应用未安装」**
签名不一致或 ABI 不匹配。先卸载旧版本再装，或改用 `universal` 包。

**模型报 400，或一直转圈**
检查 Base URL 与 Chat Path 是否拼错（常见 `/v1` 重复）。部分端点不支持 `tools` 参数，可先关掉联网搜索再试。

**联网搜索没反应**
Tavily 需要在「设置 → Tavily API Key」填密钥；选 DeepSeek 后端时，要求该提供商已填 Key。

**图片发出去，模型说看不到**
该模型没开「支持图片输入」。到模型配置里勾选；未勾选时图片只发一行文字说明，不会上传像素。

**消息底部的 token 数和账单对不上**
用户消息的 token 是本地估算值，带 `~` 前缀；只有端点返回 `usage` 时才是真实计费值。

**老设备卡顿**
关掉「实时渲染」，减少单轮工具调用数，避免一次附加多个大文件。

**数据存在哪**
`Android/data/xyz.zip8919.app.aichat/files/`。卸载即删除，需要保留请自行备份。

## 安全提示

- 所有会话、附件与配置只存在本机，不上传任何统计数据。
- 图片与文件附件会随请求发给模型服务商，请勿附加敏感内容。
- 为兼容老设备，当前版本**不校验证书与主机名**，请勿在不可信网络中使用。
- 「反馈建议」入口尚未接入后端。
